# Decisão vigente: disparos sem PDF

Em 19/10/2026 às 9h09 (Pernambuco), o proprietário determinou abandonar definitivamente o envio de cartões PDF e retornar ao padrão web convencional anteriormente preservado como reserva. Esta decisão substitui a decisão das 8h48 que havia adotado o PDF com legenda como modelo permanente.

Formato solicitado para o disparo das 7h: cabeçalho institucional normal, saudação e data/hora, CONSULTAR TAREFAS com link individual para quadro.html e TAREFAS DE TERCEIROS somente quando o servidor autorizar supervisão. Aviso ESTA MENSAGEM CANCELA AS ANTERIORES. Toda a operação ocorre nas páginas web. Nenhum PDF deve ser enviado, nem como formato principal nem como reserva.

O usuário pediu a prévia visual antes de outro disparo emergencial. A prévia foi apresentada nesta etapa. Não houve novo envio nem alteração remota da instalação Windows por esta decisão. Será necessário aplicar a retirada dos caminhos PDF no executor antes da próxima substituição. Não executar os instaladores anteriores que reativam enabled/daily para PDF.

Continuam vigentes as demais regras aprovadas: lista individual apenas com códigos coloridos de tarefas não concluídas; dispensa de escolha de folga para visitantes configurados pelo proprietário; falha de apagamento não bloqueia o envio do dia após as tentativas e gera tarefa urgente de limpeza manual; preservar recibos e impedir repetição de envio incerto. O pacote de continuidade foi preparado anteriormente, mas sua instalação no Windows ainda não foi confirmada.
