# Manuais por perfil — Assistente FSJ

**Regra vigente (26/10/2026).** O sistema tem cinco manuais distintos: [Proprietário](PROPRIETARIO.md), [Gestor](GESTOR.md), [Funcionário](FUNCIONARIO.md), [Visitante](VISITANTE.md) e [Outros](OUTROS.md). O manual geral de operação e manutenção é de uso exclusivo do Proprietário.

Cada manual deve começar suas seções com uma **captura real e atual** da tela correspondente (desktop e celular, quando aplicável), antes da explicação. **Capturas ainda não incorporadas**; não substituir por imagens antigas ou fictícias. Ocultar nomes, telefones, tokens, senhas e demais dados pessoais antes de publicar. Os exemplos de caminho de imagem são marcadores, não imagens existentes.

## Controle de acesso

| Perfil | Entrada | Operação | Manutenção/arquitetura/código |
| --- | --- | --- | --- |
| Proprietário | Autenticação administrativa | Todas as funções | Exclusivo |
| Gestor | Autenticação de gestor | Mesma configuração operacional do Proprietário, no escopo autorizado | Proibido |
| Funcionário | Link pessoal do WhatsApp | Somente funções permitidas | Proibido |
| Visitante | Link pessoal do WhatsApp | Consulta/demonstração autorizada | Proibido |
| Outros | Link pessoal do WhatsApp | Facilidades específicas configuradas | Proibido |

**A configuração feita pelo Proprietário/Gestor deve ser aplicada no servidor.** Ocultar botão não equivale a impedir acesso. Não incluir credenciais nem links com tokens reais nos manuais. Esta documentação estabelece a regra solicitada; não comprova que todos os controles de acesso já estejam implantados ou testados.
