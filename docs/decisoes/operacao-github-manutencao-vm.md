# Operação no GitHub e manutenção na VM

Decisão do Proprietário em 29/10/2026: manter o acesso operacional pela Internet via GitHub e concentrar desenvolvimento e manutenção na máquina virtual. O código reservado deve ficar em repositórios privados; segredos e dados sensíveis não devem ser entregues aos navegadores nem publicados no GitHub Pages.

O GitHub não oferece privacidade por pasta dentro de um repositório público. A migração exige repositório privado e hospedagem compatível, preservando URLs operacionais, atualização automática, sessões e permissões. Código de interface entregue ao navegador permanece inspecionável. Dados operacionais e autorização continuam no servidor protegido; GitHub Pages hospeda as telas estáticas e não substitui o banco/API.

Estado desta entrega: decisão registrada. O repositório operacional urbanopos/Assistente.FSJ permanece público; sua visibilidade e hospedagem não foram alteradas durante a correção dos botões. Acesso à VM indisponível nesta sessão: nenhuma instalação ou transferência de manutenção na VM foi realizada. Não apresentar esta decisão como migração concluída.
