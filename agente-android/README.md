# Agente FSJ — Android (protótipo de instalação)

Esta etapa compila um APK de **teste de instalação e controle local**.
O botão Desativar interrompe o estado local do agente.
**Não há envio automático nem acesso ao WhatsApp nesta versão.**
O APK não deve ser anunciado como solução de disparo automático.
A distribuição é debug, somente para teste controlado no Samsung S23 do proprietário.
Workflow: .github/workflows/agente-android.yml. O GitHub Actions compila e publica downloads/agente-fsj-teste.apk se o workflow executar com sucesso e tiver permissão de escrita.
