Orientações para fechar o Chrome

Esta página é uma orientação de manutenção do acesso individual. Ela não altera seu cadastro nem permite acessar tarefas sem um link válido.

  1. Abra a tela de aplicativos recentes do celular.
  2. Deslize a janela do Chrome para cima para fechá-la.
  3. Quando receber uma nova mensagem do Assistente FSJ no WhatsApp, abra o link CONSULTA TAREFAS dessa mensagem.

Se aparecer “quadro expirado ou inválido”, solicite um novo link individual ao responsável. Não use mensagens antigas.

A identificação e as permissões de Visitante devem ser confirmadas pela Central antes de exibir tarefas.
