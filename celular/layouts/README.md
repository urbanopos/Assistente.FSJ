# Layouts oficiais — Celular

Cada perfil possui seu próprio `index.html` em `celular/layouts/<perfil>/`.

- `executor/index.html`: layout Executor.
- `supervisor/index.html`: layout Executor com Supervisão (Menininha).
- `proprietario/index.html`: entrada provisória; depende da implementação/validação do layout móvel real do Proprietário.

Os registros operacionais e permissões são compartilhados, não copiados para estas pastas. Não excluir versões legadas até homologação de todos os acessos e navegação.
